### 月干支推算（年上起月法）

口诀：**甲己之年丙作首，乙庚之岁戊为头，丙辛必定寻庚起，丁壬壬位顺行流，若问戊癸何方发，甲寅之上好追求。**

| 年干 | 正月（寅月）干支 |
|------|------------------|
| 甲、己 | 丙寅 |
| 乙、庚 | 戊寅 |
| 丙、辛 | 庚寅 |
| 丁、壬 | 壬寅 |
| 戊、癸 | 甲寅 |

正月起寅，顺数至目标月，六十甲子循环。
例：2026 丙午年，年干丙 → 正月庚寅 → 二月辛卯 → 三月壬辰 → ……

### 时干支推算（日上起时法）

子时起，顺数至目标时辰（子丑寅卯辰巳午未申酉戌亥），六十甲子循环。

### 日干支推算

用已知锚点 + 60 甲子循环推算：
- **主锚点**：2026-01-01 = 乙亥日（0-based 序号 11）
- **验证锚点**：2026-01-31 = 乙巳日（0-based 序号 41）—— 跨表交叉验证
- 计算目标日期与主锚点的天数差 → `(11 + 天数差) % 60`（负数差先加 60 的倍数）→ 查 60 甲子表得日干支
- **准确性防线**：日干支是四层防线中最易错的一环。如环境允许，计算后用 lunar-python（`pip install lunar-python`）离线交叉验证；无法验证时，输出中标注「日干支未经历法库交叉验证」

### 流年紫微宫位

**标准口径**：流年命宫 = **流年地支所在宫**（当年太岁宫）。
- 例：2026 丙午年 → 流年命宫在**午**宫，与出生年份无关
- 实证：iztro 源码 `FunctionalAstrolabe.js:77` `yearlyIndex = fixEarthlyBranchIndex(yearly[1])`，`yearly[1]` 即流年地支
- ⚠️ 旧版曾用「寅宫起 1 岁顺数虚岁」公式，经验证为错误口径（同例得出寅宫），已废弃。降级口算时一律用本标准口径；主线以 `scripts/pai_pan_ziwei/` 引擎输出为准
