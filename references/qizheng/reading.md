# 七政四余判读操作手册（引擎字段 → 原典检索路由）

> 本手册是七政盘的**操作入口**——说明 `scripts/pai_pan_qizheng.py` 输出了哪些字段、如何通过 `scripts/mingli_query.py` 检索清理后的七政典籍语料（`references/corpus/qizheng_*.jsonl`，辑自殆知阁《张果星宗》《星学大成》《乾元秘旨》），以及有哪些学派边界与不做范围。
> 排盘数字一律以 `scripts/pai_pan_qizheng.py`（或 `build_chart.py`）输出为准，解读服从盘面，不能反过来改盘。

## 一、引擎输出字段 → 检索路由

| 引擎 / chart 字段 | 引擎含义 | 原典检索命令 / 语料库 | 判读重点 |
|--------------|---------|--------|---------|
| 命度（X宿N.NN度，度主五行Y） | 真升点恒星黄经所躔宿 | `mingli_query.py search --system qizheng -q "宫度主论 命度"`；`qizheng_classics.jsonl` + `qizheng_stars.jsonl` | 度主定我 |
| 十一曜表·躔宿+入宿度 | 每曜躔二十八宿何宿几度 | `mingli_query.py search --system qizheng -q "<星名> 躔度 升殿"`；升殿表见 `states-tables.md` | 躔度断 |
| 十一曜表·躔宫（支宫） | 每曜落十二支宫何宫 | `mingli_query.py search --system qizheng -q "<星名> <宫名>"`（`qizheng_stars.jsonl` + `qizheng_palaces_geju.jsonl`） | 入宫断/照宫断 |
| 十一曜表·宿五行 | 曜之五行（日火/月水/罗火/计土/孛水/气木） | 庙乐旺制刑关系律见 `references/qizheng/states-tables.md` | 状态断 |
| 昼生/夜生 | 日出日落太阳高度判定 | `mingli_query.py search --system qizheng -q "阴阳并明 明晦 昼生 夜生"` + `states-tables.md` | 昼夜取重 |
| 立命宫（X宫，宫五行Y） | 果老安命法（太阳加生时顺数至卯） | `mingli_query.py search --system qizheng -q "命宫 拦驾经 宫主"` + 宫度生克 | 立命宫义 |
| 难仇恩用表 | 以命度宿五行为我 | `mingli_query.py search --system qizheng -q "恩用难仇 磨赋 生杀星论"` | 恩用难仇 |
| 盘面格局 | 十一曜分布组合 | `mingli_query.py search --system qizheng -q "<关键字>" --layer geju`（先核成立条件再看破格） | 格局断 |

## 二、口径注（判读前必读）

1. **命度与立命宫是两个口径**（引擎同出）：果老以度主为要、宫主次之（见 `qizheng_classics.jsonl` 十一·看盘活法：
   「须是以度主为要，宫主次之……夜生人重身度主，日生人重命度主」）；乾元派则主「定命专论宫，行限专论度」。
   本仓两口径并出，判读各自成段，不混用。
2. **身宫/身主引擎未算**：「第一重身主」之断（宫度主论）存参不引；夜生盘按典籍注明「重身度主」之限，
   但不得凭空补身宫。
3. **恩用难仇两口径**：引擎以命度宿五行为「我」；磨赋原例以立命宫宫主为「我」。引用磨赋条文时注明
   其为例口径，与引擎表并列呈现。
4. **明晦昼星清单有传本异文**（孛/计互倒，见 `states-tables.md` 三注）：取共同集昼星=日木土水气、
   夜星=月火金罗；涉孛/计取舍时在断语注明所据条目。
5. **限度/小限/流年倒限不做**：引擎未算行度，`张果星宗` 卷十六十七（洞微百六限/倒限诸篇）不入本库，
   解读不引、不断流年吉凶应期。
6. **变曜/化曜/神煞层不做**：果老卷二至四之变曜（甲火乙孛丙属木…）、天官福禄、科名禄勋等依赖年干起例，
   引擎未实现，本库不收、解读不提。
7. **庙旺已可查表**：自 v2 起，升殿（宿表）与庙乐旺制刑（宫五行关系律）按 `states-tables.md` 对照引擎
   躔宿/躔宫即可断，不再受「本仓不判庙旺」旧限；但**宿内分度**的庙旺细分（几分几度）仍不判——引擎只出
   入宿度数，古表分度各派差异大。
8. **恒星制**：躔宿与回归制排盘软件差约 24°，属学派口径（引擎文件头 1-3 条），有用户对盘疑问时引用
   此说明，不改盘。

## 三、断语纪律

1. **每条论断挂原典出处**：标明条目 ID、书名·卷·小节及引文；自建五行推导注明「按喜宫歌关系律推」。
2. **现代转译克制**：典籍原句客观引用，解读时将古代吉凶极言转译为顺阻节奏、资源位置、内在功课与可行动建议，避免宿命恐吓。
3. **引擎没算的、本库没载的，不硬编**（口径注 5/6 的洞微大限、倒限、年干神煞不凭空补算）。
4. **单曜断先看状态再落强弱**：同一曜同一躔宿，昼夜/四时/会合/升殿不同则分量不同；同时注意宿界仅为近似参考，近宿界点需在解读中说明。
5. **十二宫断先宫后曜**：先看宫义与宫度关系，再看守宫星与对照星，两层不混。

## 四、最小判读序

1. **昼夜定主**：先分昼生（重日）/ 夜生（重月）与命度/命主得时与否
2. **命度度主**：定「我」五行，排难仇恩用
3. **立命宫**：看立命宫支及宫主与度主生克
4. **命宫与强宫守曜**：查守命宫与官福田财妻诸星（`mingli_query.py chart-lookup`）
5. **恩星与难星**：分看恩星得地与否、难星有制与否，结合升殿/庙旺喜忌表作整体判断
