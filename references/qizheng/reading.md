# 七政四余判读操作手册（引擎字段 → 原典检索路由）

> 本手册是七政盘的**操作入口**——说明 `scripts/pai_pan_qizheng.py`、`scripts/qizheng_dynamic_facts.py` 与 `scripts/build_chart.py` 输出的全部字段、如何通过 `scripts/mingli_query.py` 检索清理后的七政典籍语料（`references/corpus/qizheng_*.jsonl`，共 5 份 437 条，辑自殆知阁 Public Domain《张果星宗》《星学大成》《乾元秘旨》），以及已锁定的学派口径。
> 排盘数字一律以确定性引擎输出为准，解读服从盘面，不能反过来改盘。

## 二、已锁定学派口径（`calibrated-v3`）

1. **恒星制与二十八宿逐星校准**：原点为角宿一（Spica，α Vir，HIP 65474），全 28 颗距星采用 CDS SIMBAD ICRS J2000 坐标与自行，逐星岁差至日期平黄经；觜宿取古距星 φ¹ Ori、参宿取古距星 ζ Ori，规避现代 λ Ori / δ Ori 岁差“觜参易位”，全 28 宿严格单调。十二支宫直接由校准宿界按《汉书·律历志》十二次分野聚合。
2. **太阳与行星星历精度**：太阳采用仓内 VSOP87 级数几何平黄经（1900–2100 对 404 组 NASA/JPL Horizons 向量最大误差 `< 0.0001°`）；月与五星对 404 组 JPL 向量误差 `< 0.055°`。距校准宿界 `<= 0.1°` 仍输出近界提示，建议兼核邻宿。
3. **紫气锚点**：沿用 Moira / 现仓通用回归 28 年锚点（1975-03-13 16:00 UT = `230.5°`，日行 `+360/10227.1792°`）；计都取罗睺平升交点对冲。
4. **命度、立命宫与身宫三主并出**：果老以度主为要、宫主次之，夜生重身度主、昼生重命度主；身宫采果老正宗以太阴所在宫为身宫、其宫主为身主、太阴躔宿为身度。
5. **洞微大限起法**：采用《张果星宗》卷三/十六与《星学大成》出童限折算法（命宫按太阳入宫归一化度 3°=1 岁折算 `10~20` 年，余十一宫按 `10/11/15/8/7/11/4.5/4.5/4.5/5/5` 年顺地支/逆黄经行宫度），同步输出量天尺起度、实时限度宿与生日换宫小限。
6. **年干变曜与神煞**：严格以物理立春交节换年，采用《张果星宗》卷二果老正宗十干变曜（甲火乙孛丙木…化禄暗福耗荫贵刑印囚权管库星）及完整年干支神煞（科名/文魁/官印/天乙玉堂/禄勋阳刃/驾前驾后神煞）。
7. **明晦传本异文**：《张果星宗》明晦两条对孛/计互倒，引擎取共同集（昼星=日木土水气、夜星=月火金罗），孛/计标注「传本异文待参」。

## 三、断语纪律

1. **每条论断挂原典出处**：标明条目 ID、书名·卷·小节及引文；自建五行推导注明「按喜宫歌关系律推」。
2. **现代转译克制**：典籍原句客观引用，解读时将古代倒限/煞刃极言转译为顺阻节奏、承压窗口、资源位置与可行动建议，避免宿命恐吓。
3. **单曜断先看状态再落强弱**：同一曜同一躔宿，昼夜明晦/升殿/喜宫/忌躔失陷不同则分量不同；距宿界 `<= 0.1°` 时须兼看邻宿。
4. **体用分看**：先立原盘（静体：命度/立命/身主/强宫守曜/变曜），再看行限与流曜（动用：洞微限宫限度、小限、流年太岁与过宫），两层互参不混淆。

## 四、标准判读序

1. **昼夜与三主**：先分昼生（重日与命度主）/ 夜生（重月与身度主），定命度、立命宫与身宫/身主关系。
2. **恩用难仇与强弱宫**：排难仇恩用，查命/官/福/田/财/妻强宫守照曜及升殿/庙乐旺制刑/明晦状态。
3. **年干变曜与神煞**：查天禄（官）、天权（命）、天福（财福）、天荫（妻）、天印（田）及天囚/天刑/阳刃/劫亡落宫。
4. **洞微大限与流运过宫**：核当前大限限宫与限度主生克（结合 `mingli_query.py chart-lookup` 检出的洞微/倒限原典），并用 `scripts/qizheng_dynamic_facts.py` 核查流年太岁、流月/流日过宫与原流交汇。
