# 丑月辛金的本命专业发展条件

按本卡做 `conditional_module_only` 人工判读。先核同一出生候选的完整四柱，再按 [M0](../../docs/model-judgment.md) 复审作用和反证。

## BZ-QXC01 · 专业发展配置相对有利

项目释义：本命辛日生于节令丑月，原局丙、壬俱透，至少一支实藏丙且癸不透。完整前提已核、复审未见已成立的用途否定时，可判断传统模型内的本命专业发展配置相对有利。

### 盘面与复审

1. 精确档取本次已核的 `bazi_core_reading.facts`。出生钟面有不确定性时，按[时间合同](../../docs/time-contract.md)核可达范围。总控枚举读 `bazi_scenario_comparison.candidates[].analysis.facts`，独立时辰或钟面区间排盘读 `candidates[].analysis.facts`。记录实际候选 ID 与时间范围。缺时柱或其他决定性事实时暂缓本条完整正评，已核部分可保留。未穷尽的数值见证按已实际覆盖的范围表达。
2. 查 `day.stem` 与 `month.branch`。丑月由排盘采用的出生节令确定，为小寒至立春之间。查原局年、月、日、时的 `stem`，标出丙、壬实际透在哪柱并核癸是否同透。查四支的 `hidden`，至少一处须实藏同干丙。仅见其他火藏干、丙或壬仅藏，以及来自后天层的干支都不能补足条件。
3. 说明丙在季节解释中的主要角色和壬的辅助角色。列实际位置、针对所需作用的反证与可能改判的条件。例如丙辛同见时，先核具体位置和有无足以否定所需作用的依据。只有一般配对而效力未决时，保留条件方向，同时说明其稳健性。若适用依据已否定丙或壬承担该用途，撤回正评。
4. 保存原始事实指针、所问目标、逐项前提、退出条件、判断及独立复审，单列模型方向和稳健性。某个候选满足、另一候选退出时，按各自出生范围作答。缺一条件只退出本条正评，其他分支各需依据。

### 表达与适用范围

完整匹配时，直接说明在这一传统读法下，专业积累转化为成果的本命配置相对有利，并解释支持来自哪里、哪个未决作用会改变判断。藏同干丙与避开癸透是本条采用的保守操作边界。癸透使这条正评退出，其实际作用仍需另查。戊己和丙壬藏透的其他组合各有原文语境。

本卡只评价本命专业发展配置。问阶段、某日某月、资源、关系、健康或具体录用和成果时，对该对象另查已获准的依据。长期与短期答复均只在与原问相关时交代这项本命背景，给时段顺阻还须核该时段的支持、代价与反证。记录保留为人工模块判断，引用使用项目释义。

### 来源定位

文明書局 1926 年《滴天髓·穷通宝鉴》第 2 卷 PDF76，版心三十一，自「十二月辛金」大字标题起。乾乾书社 1937 年《穷通宝鉴评注》PDF213，卷四版心四十七，同题大字底文及徐乐吾小字评注，小字续至 PDF214 右端。底文均对丙先、壬后及俱透给出评价，评注支持丙为主、壬为佐。专业发展是对原书评价的受限现代转译。两版沿同一文本传统。书目、扫描指纹、影像位置及身份见[来源审计](../../docs/bazi-qiong-xin-zi-sources.md#丑月辛金的本命用途)。
