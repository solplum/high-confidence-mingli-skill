# 寅月甲木的本命专业发展条件

按本卡做 `conditional_module_only` 人工判读。先核同一出生候选的完整四柱，再按 [M0](../../docs/model-judgment.md) 复审所需作用和反证。

## BZ-QJY01 · 学习支持与专业成果相配

项目释义：本命甲日生于节令寅月，原局丙、癸实际俱透，两干之间至少隔一柱，且各有一处或以上实际藏同干。查清两干依赖路径，在所需作用仍成立的条件下，可判断传统模型内可用的学习材料或反馈与形成可核验专业成果相配，这条本命发展配置偏有利。

### 盘面与复审

1. 精确档取已核的 `bazi_core_reading.facts`。出生钟面有不确定性时，按[时间合同](../../docs/time-contract.md)核可达范围。总控枚举读 `bazi_scenario_comparison.candidates[].analysis.facts`，独立时辰或钟面区间排盘读 `candidates[].analysis.facts`。记录候选 ID 和实际覆盖范围。缺时柱或其他决定性事实时，暂缓完整正评。
2. 查 `day.stem` 为甲，`month.branch` 为寅。寅月以出生节令立春至惊蛰的区间确定。查原局四柱 `stem`，核实丙、癸各透在哪柱，两干之间须至少隔一柱。再查各柱的 `hidden`，定位实藏丙和实藏癸。分别记录实际间隔及相碍证据。仅见同五行其他藏干、丙或癸仅藏，或后天层出现丙癸，都不能补足本条条件。
3. 说明底文的丙癸俱透正支，另标徐评以丙为主、两者配合且不相碍的解释。主动核丙、癸对本题所需的作用与实际反向关系，例如实见丙辛、戊癸配对，所依赖根支受冲合，或金、水作用与本条竞争。夹柱及藏根是盘面事实，作用仍需复审。已成立的反证阻断任一所需作用时，撤回正评。一般配对或同轴影响尚无裁定时，给出所依赖的条件、该条件怎样影响结果及稳健性，保留实际反证。不同读法若对结论有影响，分别说明。
4. 保存盘面事实指针、所问目标、逐项前提、退出条件与独立复审。候选结论有别时按实际出生范围分别交付。缺少本条必要条件，只退出本条正评。丙透癸藏是原书的另一支，需单独取得适用依据。

### 表达与适用范围

完整匹配时，直接交代学习材料或反馈与形成可核验专业成果相配的局部条件方向。专业成果是项目对原文评价的受限现代转译。实际藏丙、藏癸是本条采用的保守操作边界。现实中是否具备可用反馈、材料与相应权限，按用户提供的事实说明，与命理的配置判断分开记录。

本卡仅评本命的上述专业发展配置。大运、流年、流月、流日及其他领域各查独立依据。具体录用、收入、成绩、作品完成和整盘净吉凶均超出本卡用途。判断保留为人工模块记录，使用项目释义。
