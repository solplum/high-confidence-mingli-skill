# Fortune-Specific — 推算查询 Workflow

处理具体问题的个人分析。先读取 `workflows/fortune-auditable-reading.md`，执行固定输入、覆盖计划、单盘证据、独立反审、对照与交付的共同流程；本文件补充问题范围，不另设快捷路径。知识检索遵循 `knowledge/README.md`。

输入：用户问题、已有命盘与本次引擎快照。用户画像仅用于理解关注点和调整表达，不替代盘面证据。

## Phase 1：明确问题和覆盖范围

将问题拆成可分别检查的子问题，区分传统结构解释与现实决策所需事实：

| 类型 | 要检查的内容 |
|------|----------------|
| 结构性，如事业方向 | 相关原局字段、规则前提、相反信号；运段另列，不能由术语直接推出职业 |
| 时机性 | 所问时间区间、原局与当期字段、实际边界和现有规则是否支持该时间尺度 |
| 关系性 | 双方资料的范围、单人盘的限制及现实互动；他人想法和关系结果不由单人盘确定 |
| 方向选择型 | 各方向的传统解释条件、反向信号，以及技能、资源、成本等现实核查问题 |

例如“适合创业还是打工”可检查原局相关结构、当前运段条件和两种选择的现实约束，而不是先把官禄、财帛或十神直接等同选择结果。只补问会改变分析的缺失信息；其他缺口进入覆盖计划。

输出：`{ sub_questions: [{ topic, aspects }], question_type, focus_layers }`。
兼容：旧消费者需要 weights 时保留空对象并标注 deprecated，不填造数值，不用于合成。

## Phase 2：按子问题深入单盘

按共同流程分别分析可用体系，先冻结各自记录，再看其他体系的结论。每个相关子问题完成以下对应工作：

- **八字**：从实际四柱及相关衍生字段出发，区分旺衰、调候、格局、十神关系和运段；读取已有解读模块及适用的登记释义，检查必要条件、排除条件和未评估部分。
- **紫微**：从实际宫位、星曜状态和已输出的关系出发，按问题检查相关宫位及其相互关系；原局、大限、流年分开。完整四化、借星、辅煞或其他组合未获字段和规则支持时保留缺口。
- **七政**：使用现有 `qizheng_rule_reading`；仅在用户明确选择乾元宫主参照时使用 `qizheng_traditional_reading`。结构面板的条件及 withheld 状态按共同流程保留，不改写成人生事件断语。

检索从知识来源门的实际登记条目开始。把检索词、返回条目或无匹配结果写入本次工作记录；引文按实际资料层级定位，不能只填一个传统书名。已有模块的输出也须核对适用条件，不能将生成摘要直接当成完成分析。

每项主要判断记录盘面字段、资料、现代转译或综合环节、条件核对、反证、替代解释、边界与结论状态，连接合法 ledger claim 或原生模块人工解释记录。受限七政面板保留自身字段和来源记录，不转成不获授权的 ledger claim。缺盘、关键规则缺失或无法核查时写明具体影响；现代词未逐条登记不单独构成拒绝解释的理由。

## Phase 3：独立反审后对照

先完成共同流程规定的独立反审和审阅处理记录，再进行同领域、同时间范围、相容场景的对照。

- 方向选择保留各方向成立与不成立的条件，不以盘数或评分做决定。
- 时间问题核对查询区间内实际可能改变结论的边界；只讨论现有字段和规则支持的时间层。无法检查的窗口明确暂不判，不由长期结构细化出月份或日期。
- 合参只对照已冻结的单盘判断，列一致、冲突、范围不同或信息不足，并保留共同依赖。七政受限面板不参加个人事件合参。

输出可保留：`{ analysis: [{ sub_question, synthesis, citations, confidence }], direction_comparison, time_window, core_tension, practice_advice }`，并回指本次覆盖记录和 claim ID。

## Phase 4：按主题交付详析

开头直接回答当前能支持到什么程度，再围绕每个主要子问题展开：

1. 本盘具体支持什么解释。
2. 哪些字段及登记规则支持它，必要条件是否满足。
3. 哪些反向信号、竞争解释或候选场景改变判断。
4. 当前不能判断什么，什么现实信息能进一步区分。
5. 现实中可核查、低风险的行动。

正文附可追溯的依据摘要或 claim ID；引用索引按“登记资料名＋固定版本＋文件/行号＋资料层级”提供。篇幅由问题覆盖和证据充分性决定，不能因已引用若干条、已有流畅结论就提前结束。结尾说明已完成的检查与实质缺口，完整工作记录供复核。

## 约束

- 旧 confidence 字段若保留只填写条件与信息限制，不填写概率或可靠度星级。
- 不按固定比例分配叙事或将缺失层转移到其他层。
- 传统解释与现实决策依据分开，建议回到用户的现实约束，不替用户选择。
