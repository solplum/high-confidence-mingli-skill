# Fortune-Specific — 具体问题推算流程

> 适用于「近期换工作还是留原单位？」「这段关系值不值得推进？」「副业/合伙能不能做？」「未来两年重点考公还是进企业？」。

## 一、先界定现实问题与边界

若用户的提问缺少关键背景（如只问“我今年能发财吗”或“我们合不合适”），先快速用 1–2 句追问澄清（或直接按既有 `memory.md` 背景推进并标明前提）：
- **事业类**：目前行业/岗位类型、面临的具体二选一选项与期望时间窗口；
- **感情类**：单身寻缘 / 暧昧观察 / 长期关系磨合 / 婚姻抉择；若已有对方出生信息，可另建对方盘对照，否则只立足本命盘与行运互动分析；
- **财运类**：主业加薪、创业合伙还是资产投资。

## 二、聚焦盘面与原典查证

1. 确保已有三盘快照（见 [建档流程](../docs/onboarding.md)）；若只需看大运或某领域，注意同时传入正确 `--analysis-year`。
2. 针对问题主题检索原典（`career` / `love` / `wealth` / `health`）：
   ```bash
   python3 scripts/mingli_query.py chart-lookup --chart-json ~/.claude/fortune-telling/snapshot.json --topic <topic> --limit 5
   ```
   按具体宫位/十神补充检索 `scripts/mingli_query.py search`（例如问合伙查 `兄弟 比劫 交友`、问置业查 `田宅 正印`、问考试晋升查 `印星 化科 文昌 文曲`）。
3. 若问题聚焦某一年/月/日窗口，配合 `scripts/ziwei_dynamic_facts.mjs` 与 `scripts/qizheng_dynamic_facts.py` 检查当年/当月/当日动态宫位、四化、洞微限度与流曜过宫，并与八字当前大运/流年十神对照。

## 三、三盘对比与落地回答

按「**先结论 → 分盘机制 → 反对条件/风险 → 可落地策略**」回答：
1. **直白结论**：给出明确倾向或条件式抉择（例如：“现阶段大运助官印而流年冲动驿马，适合依托现有积累向内部更高权限岗位争，而非裸辞跨入陌生重资产领域”）。
2. **三盘相互印证与不同视角**：
   - 八字侧重看外在时运风向与用神得失；
   - 紫微侧重看事件发生在哪些宫位、牵动哪些人际资源及本人主观感受；
   - 七政侧重看该领域主星、身主、年干变曜（天禄/天福/天荫/天印等）、恩难强弱与当前洞微大限/流曜过宫引动（缺经纬度则说明略过）。
3. **明确反证与变化拐点**：说明“在什么前提下这个判断会反转”（如出生分钟跨时辰、某一月节气前后的转变、或实际执行中若缺某关键条件则不宜强推）。
4. **行动清单**：给出 2–4 条具体、不过度玄学化的可行动建议。
