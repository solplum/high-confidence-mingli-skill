# Fortune-Resonance — 命理共鸣与说法核对流程

> 适用于「我在小红书/视频号刷到说“X日主今年走偏财会暴富”」「别人说我是紫微天府格/伤官见官，我到底是不是？」「为什么我看了个解读特别准，真是这个原因吗？」。

## 核心思路：先核真伪，再解机制，不凑合瞎附会

网传爆款命理文案常犯三个毛病：**断章取义单个字/单颗星**（忽略月令调候、四化庙旺与破格条件）、**偷换学派口径**（比如把飞星自化硬安到三合盘上，或用虚岁套八字），或者**泛化巴ナム心理学话术**。

## 执行步骤

1. **提取网传原命题**：把用户带来的说法拆成 1–3 条具体可核查命题（例如：`① 命主是否为“食神制杀格”`；`② 所谓“壬水见寅月必暴富”是否原文有载`；`③ 对应该说法在命盘上真正生效的前提是什么`）。
2. **回盘核验事实**：
   - 如无命盘先建档（`docs/onboarding.md`）；有盘则读取 `~/.claude/fortune-telling/snapshot.json` 与 `chart.md`，核对用户说的星曜、十神、格局、亮度和大运是否真在盘上，还是把**虚岁当大运、借星当本宫、现代网文当古籍**。
3. **用 `scripts/mingli_query.py` 查原典真意**：
   - 查《穷通宝鉴》《子平真诠》《滴天髓阐微》《紫微斗数全书》《张果星宗》原文上下文（注意网传经常只截取前半句“大贵”，隐去后半句“最忌见某煞破格”或季节前置条件）。
   - 如涉及**飞星宫干四化**（本仓紫微默认为三合《天纪》固定四化），加上 `--include-feixing` 明确指出学派差异，不混为一谈。
4. **交付判断（逐条对照，绝不和稀泥）**：
   - 明确指出每条网传说法是 **「盘面成立且有原典依据 / 半真半假（缺成立条件或有破格） / 与实际盘面或原典不符 / 属另一学派体系」**；
   - 如果用户表示“但我现实里确实很像/确实经历过”，从三盘结构中找出**真正对应他体验的机制**（例如并不是因为那个假格名，而是因为某柱贴身强根＋当前大运引动），帮他看懂背后真正的命理逻辑。
