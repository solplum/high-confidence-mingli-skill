# 八字结构解读 v2

版本：bazi-structure-v2（原结构段落 + 月令候选增量）。实现 scripts/bazi_core_reading.py。此版本是项目编写的计算规则说明，不引用古籍原话，不使用独立 CC BY-SA 学习卡的文字作为输出。用途为把引擎既有四柱关系解释清楚，不能作为预测验证、完整详批或个人诊断。未更改排盘算法。

## 输入与证据

输入为 pai_pan_bazi.compute 的 pillars。每个已知柱的天干、地支、十神、藏干必须与同引擎的 GAN、ZHI、CANGGAN、shishen_of 完全相符，否则报错；不静默修补。这里核验局部符号及派生字段，不认证出生记录，也不检查四柱之间的完整历法一致性；调用方仍应从引擎取得四柱。时柱可未知，未知柱不参与检出。输出保留柱位事实、关系、相邻性、月令透干、每段前提、反证和未决项；源文件 SHA-256 与规则版本在 JSON 中保留。每段 evidence 指向 facts 的柱位键。

## 五个栏目及边界

1. 冲合：按六冲（子午、丑未、寅申、卯酉、辰戌、巳亥）、六合（子丑、寅亥、卯戌、辰酉、巳申、午未）、六害（子未、丑午、寅巳、卯辰、申亥、酉戌）、子卯刑、辰午酉亥同支双见检出不同柱位配对。三合、三会、寅巳申/丑戌未三刑仅报告三种字全部存在，缺字不推断两字刑或半合。天干甲己、乙庚、丙辛、丁壬、戊癸只报告配对，记录隔柱，不推断合化、合绊有效。重复字不去重柱位，同一柱不能与自己成对。未检出不代表所有学派关系已穷尽。
2. 十神：沿用引擎日干参照系。五行序木火土金水，顺一为生，顺二为克，逆一为受生，逆二为受克。年到时仅为显示顺序，不是人生发展顺序或实际能量流。每条邻接路径保留两端柱位，生克兼列，不虚构贯通链。
3. 格局：月支所有藏干逐个比对年、月、时天干，精确同干才报告透出；日干单列不参与“外部十神透出”。只完成取格前证据，不命名已成立格局，不把月支首项当作当日司令。不计算分日司令、成败、救应。
4. 调候：寅卯辰春、巳午未夏、申酉戌秋、亥子丑冬。逐位列火水在可见天干与藏干的存在位置，不计权重，不把季节当当地气候，不由元素缺失断缺陷或推荐补救。
5. 旺衰：将日主同五行藏干称为“同五行根气位置”，不冒充根气有效性的判断。生我与同我列生扶侧；我生、我克、克我列克泄耗侧。日干自身不重复作生扶证据。月支首列本气只作元素关系。禁止计数强弱、无根即从、有根即强、合即化、唯一喜忌结论。

## 来源身份

基本符号表与仓库引擎的传统通行表同口径；地支配对可与 references/bazi/wuxing-tables.md §§天干五合、地支关系对照，但本模块只采用集合/配对定义，不采纳其中“力量减半”、人生对应、合化已成等推论。该旧文件是来源身份未完全核清的项目参考，不称已校勘古籍。运行时依据为本文件及引擎实现的版本化定义，不冒充通过 claim ledger 的个人结论。

## 交付和测试

build_chart.py 默认文本用五段结构解读替代五个 agent 注释；JSON 新增 bazi_core_reading，既有 bazi 及其他字段不改。该结构解读不是最终完整详批，尚缺有前提支持的个人解释和现实问题背景。误差场景只能逐盘解释；中心候选的结论不覆盖其他时刻。未知时柱必须保留限定。tests/test_bazi_core_reading.py 覆盖季节、木日主、重复配对、合与刑害并存、缺字与全组、未知时柱、篡改输入及真实 CLI。

## 增量：月令透干候选决策 v1

`bazi_core_reading.pattern_reasoning` 现在调用 `scripts/bazi_pattern_reasoning.py`，取代原来的候选清单而不决策。其代码为 MIT；输出中格局候选解释这一独立衍生部分按 CC BY-SA 4.0，完整许可与署名在 JSON attribution 内，文本有固定来源、贡献历史、改编说明和许可链接。前述“不使用学习卡”仅适用于原结构段落，不适用于本增量。登记记录为 `bazi-dts-interpret-geju`，study-cards.md 第8行，维基文库844410版项目释义，未校勘，不称古籍原话。每次运行先验证知识目录，失败即停止，不降级为无来源判断。

这是本项目对既有传统学习卡的有界操作化，不声称古籍原文给出了完整算法。采用“月支藏干精确同字透于年/月/时干”路线，不用遥合虚神，不把日干算透出，不把本气排序当司令。只处理官杀、财、印、食伤八类；引擎称七杀为偏官，照录其名称。比劫另列不适用，不擅定建禄/月刃。四季月也不凭首项抢占优先权。

- 四柱齐、恰一类满足：明确选为优先候选（single_candidate）。该肯定针对“这条路线优先审哪个格”，不是成格。
- 多类透出：competing_candidates，全部并列，不计分、不强排。
- 无类满足：no_candidate_on_route，明确这条路线未成立，不说全盘无格。
- 缺时：incomplete_hour/withheld。可报告已知三柱的暂定候选，但候选名单与关系检查不能覆盖未知柱；未透项记unknown_exposure而非全盘否定。

每个候选分别输出月支藏干、相对日干十神、具体透出柱位、未满足或不适用理由。月支参与冲合刑害及候选干参与五合时保留双方柱位，只作为有效性待查，不自动删格、化气或相互抵销。官杀并透和伤官见官逐柱展示，反对“清纯”捷径，不直接作凶断。候选与其他透干逐项输出五行方向；食伤对偏官的克只允许说有制杀方向，效力及日主承受未证。该局部取格模块没有证明身强弱、调候、喜忌或命运。

变更条件明确：补时可能新增竞争、跨节令需重建月令依据、从候选到成格仍需有效性及救应的额外证据。单个时间候选的解释不自动覆盖误差场景；调用者必须逐场景运行后比较。新增测试包含真实节令前后、辛不替代庚透出、删除透干的反事实、多透竞争、未知时补全、比劫范围、合冲并存和官杀混杂。合成柱例只验证局部规则，不冒充历法上可发生的生日。
