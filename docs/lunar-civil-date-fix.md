# 农历民用日归月修正

本修正针对确定性的历法错误，不改变八字以节气**时刻**划分年柱、月柱的口径，也不涉及命理预测有效性。

## 根因与范围

旧实现按天文瞬时比较朔与中气。中国农历月从朔发生的北京日期零点开始，因此同日先发生的中气也属于当日开始的新月。冬至所在十一月的定位同样必须按民用日期。

2034-01-20 大寒早于同日的朔发生。旧代码把大寒错归上一月，导致 2033-12-22 被编号为十二月，并把 2034-02-19 错列为闰正月。修正后是闰十一月、十二月、正月。1984-12-22 和 2014-12-22 也覆盖冬至早于同日朔的另一条路径。

算法没有按年份硬编码例外：

1. 冬至月按 UTC+8 日期寻找当日或此前最近的朔日。
2. 中气按 `[本月朔日, 下月朔日)` 归属。
3. 保留相邻冬至月之间有十三个月时，首个无中气月置闰的规则。

## 独立日期依据

已读取香港天文台公开的公农历对照表：

- https://www.hko.gov.hk/en/gts/time/calendar/text/files/T1984e.txt
- https://www.hko.gov.hk/en/gts/time/calendar/text/files/T2014e.txt
- https://www.hko.gov.hk/en/gts/time/calendar/text/files/T2033e.txt
- https://www.hko.gov.hk/en/gts/time/calendar/text/files/T2034e.txt

其中 1984/2014-12-22 为十一月初一；2033-12-22 再次标十一月（闰十一月）；2034-01-20 为十二月初一；2034-02-19 为正月初一。测试包含这些边界及反向转换。

另有 1901–2100 年冬至段的结构测试，检查连续性、29/30 日月长、闰月数量。这只是内部一致性检查，不等于独立准确率。

## 尚未解决的精度边界

此次只修正归月规则，未更换太阳与月球天文近似模型。初步广域对照仍发现部分朔日及近午夜节气日期与天文台表有差异，因此不能宣称 1901–2100 年全部日期已通过，不能由此宣称天文时刻达到分钟级精度。完整覆盖与剩余差异以另行生成的对拍报告为准。历法对照通过也不能证明命理预测能力。
