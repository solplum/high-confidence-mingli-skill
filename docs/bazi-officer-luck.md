用户批准了这一项长期用途。使用 `bazi-officer-luck-v1` 的 `BZ-OL01`，按[登记卡](../references/approved/bazi-officer-luck-v1.md)逐项核对，单独保存人工判读。来源是文明書局 1926 年《淵海子平·子平真詮》第 2 卷《论行运》PDF 第 44–45 页。原图从第 44 页末列接到第 45 页首列，讨论甲日以酉官为用、行卯冲酉，以及本命巳酉相会、出生年支亥或未的例外。采用该段的受限项目释义。实透辛与现行正官候选是本项目核对该用法的入口条件。

## 按本命和实排运窗逐项核对

1. 先从本次总控快照或[出生候选快照](time-contract.md#已知民用出生钟面区间)取实际出生和折月配对。用 `bazi_scenario_reading.birth_luck_tables(snapshot)` 取各见证的 `analysis` 与 `windows`；只问单个已核折月年龄时，用 `luck_contexts_at_age(snapshot, folded_age_months)` 取各见证的 `analysis` 与当前 `age_window`。逐见证核四柱，确认日干甲、出生月支酉。查同一 `analysis.pattern_reasoning.candidates` 的原透干路线，定位实际透干的辛正官和酉藏辛。
2. 按已批准的 BJ01、BJ02、BJ04 独立建立可反驳的本命工作假说 H1。写明所问目标为什么依赖这条酉官路径，例如目标确实受既定规范、职责分工或验收口径约束。核实际支持、反向事实及会让 H1 退出的现实条件。辛正官候选本身不足以完成 H1。
3. 按[折月年龄窗](time-contract.md#八字大运年龄)选所问年龄或区间实际覆盖的卯大运。单年龄的 `status` 须为 `active`。各出生见证的折月年龄有差异时，分别取与该年龄相符的 `witness`。交运附近逐窗核相邻运，分别交付会改变结论的候选。缺可核运窗时仍可核对已确认的本命条件，运中方向待核。
4. 查四柱任何支是否为巳，再单查**出生年支**是否为亥或未。任一已核例外成立时撤回本条局部判断，保留有依据的其他支持或成本。出生年支、原局巳、实际大运或会改变 H1 的事实未核时，暂缓本条。H1 已被反证、原条件不符或所问时窗没有卯大运时，本条不适用。

续算返回的 `analysis` 按本次已核出生见证的四柱重建。保存该结果及实际四柱作为本次候选证据，格局候选、透出位置和折月运窗都回指同一见证。若旧快照中的候选摘要有出入，保留旧档供复审。

精确钟点总控旧档缺折月表的参考时间标记时，先核原盘是否明确记为时柱已知。若同时缺派生四柱或本命摘要，从原出生日期、时分和口径复算。保存的四柱、出生瞬间及留存运表均经核对后，可照常使用对应运窗。留存标记注明参考时刻，或两处精度均无可核标记时，暂缓选运。出现明确冲突时按原资料核实后重建。

条件完整并经复审时，可以回答「该卯大运中，维持这条已核酉官路径的条件偏受扰」。把运干的支持或成本、其他有依据的作用和仍未决的交互另列。岁、月、日支卯不替代卯大运。流年见巳时，仍按出生四柱检查原局巳。保存已核事实路径、出生候选、折月窗口、H1 的目标依据、例外核对及复审处理。该判断只覆盖这条路径及实际卯运，整体运势、职业结果、事件时点和冲合效力分别需要依据。

## 合成排盘正反例

以下均使用民用时 UTC+08 和正常建档入口。月份为引擎折月年龄，区间左含右不含。

| 合成输入 | 实排结果与判读 |
| --- | --- |
| 2008-09-11 00:15 女 | 甲寅日、辛酉月，辛正官实透。原局无巳，年支子。若所问确为既定标准的专业验收，且复审核实 H1，乙卯 `[614,734)` 内维持这条路径偏受扰。乙干的同身支持另看。相邻丙辰 `[494,614)` 和甲寅 `[734,854)` 不适用本条。 |

| 1959-09-29 14:00 男 | 辛正官在时干实透，丁卯 `[683,803)`。出生年支亥，撤回本条判断。 |
| 2063-09-23 00:15 女 | 辛正官实透，丁卯 `[662,782)`。出生年支未，撤回本条判断。 |
| 1959-09-29 12:00 男 | 丁卯 `[683,803)` 内，辛只藏酉，原透干路线缺辛正官候选，本条不适用。 |

首例的验收假设以月干实透的辛官及日支寅的甲根为依据。年、时子藏癸提供可核的印支持。年干戊有寅中同干根，可讨论生辛，也须保留制癸的反向。若有适用依据表明所需支持已经失效，重审 H1。若目标改为探索还没有固定验收口径的方案，即使卯运及盘面相同，也须重审对酉官路径的依赖。依赖不成立时，撤回对该目标的局部受扰判断。
