## 来源与模型不相容

PDF21–22 对阴长生的讨论含乙午、丁酉有根/余气。当前引擎午不藏木、酉不藏火。本模块的根严格定义为“藏干含日主同五行”，不是把原文所有根义映射成此定义；遇乙见午或丁见酉，保留藏干事实并挂 source_model_conflict，暂停趋势判定。未伪造藏干，也不声称原文错误。需另版和学派解释校勘后才可启用此条。

## 明示的项目判别边界

季节旺气只用寅卯木、巳午火、申酉金、亥子水这四个非土核心月；辰戌丑未及土日主不由本模块定势。首列藏干只是引擎序位，不代替人元司令。每一证据为独立记录，事实、支持偏强线索、支持偏弱线索、未决条件分栏；不重复包装同一位置为数个票数。

偏强条件趋势：核心月同五行 + 月支同五行主根 + 至少一个外部印比透干在已知支有同五行藏干 + 未见外部克泄耗透干 + 参与支持的干支无所列合冲争议。隐藏克泄耗仍逐项列出；此为极窄的支持优先假说，不表示所有根或印比已证有效。
偏弱条件趋势：核心月旺气克日主 + 所有已知支无日主同五行根 + 外部干无印比 + 隐藏干无生我印 + 至少一个外部官杀透干在支有根 + 相关干支无所列合冲争议。无根并不推出从格。
其他生扶与克泄耗并存者为证据相持，非宣告实际力量相等。时柱缺失、输入时间未决、阴长生争议、土季节口径缺口或相关合冲待审使结果待定。另将刑、害等已检出但 ST05 未评估的关系单独列为 unassessed_interactions，并在中文与未决项逐项说明；不能把局部趋势当成已经完成刑害效力审查。凡单一候选均只对该输入成立；时间区间必须逐候选重算，采样不能升级为全区间结论。未建模的生克效力、司令与特殊格审查明确保留，因此所有趋势均 conditional 而非定论。

月令用神是子平真诠的结构中心，不自动等于扶抑喜用五行；本模块不输出唯一用神、喜忌、幸运元素、人生事件或准确率。

## 输出与验证

现有命令、五段核心结构和事实字段不变；新增 strength_reasoning，ST01–ST05 可逐项复核。中文段落展示实际支持、反证、阻断和反转条件；JSON 保留位置、事实 ID、规则、来源与不确定性。来源登记失效时拒绝生成，不绕过来源门。此登记只开放该模块释义，不开放 classical_quote 或个人 ledger 的新来源引用。
