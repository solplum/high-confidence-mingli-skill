# 判势能力与依据缺口

2026-11-10已增加 [综合判读方法v1](conditional-judgment.md)、BJ01–BJ08人工条件比较和紫微独立动态事实/年/月主题与禄权卡。另已批准 [M0有限模型方法](model-judgment.md)和《穷通》子月辛金的窄整体／发展评价。下表区分旧自动面板与新增人工用途，不把旧未决状态当整项能力上限。

这是v3的维护盘点，说明当前资料和自动模块的覆盖，不是永久禁判表。分析者先查实际适用资料与条件：能够人工裁决的内容按统一方法给结论；真正缺少的依据具体列出，不能只因自动面板未给吉凶就停止，也不能靠新增结论栏伪造能力。

完整规则能否形成条件模型结果，与作用稳健性是否充分分开验收；适用特指反条及必要条件缺口仍可阻断。一般未决关系既不自动清除模型方向，也不作零影响。

这些缺口不要求每次分析全部补齐。按所问问题找决定性缺口：若只问工作方式，已有关系与合法现代综合可能足够；若问具体某日整体顺阻，需要真正支持这一时间层和评价对象的依据。不同领域的结论强度可以不同。

补库优先记录：要回答的问题、需要的规则/输入、已有来源覆盖、尚缺条件、反例和验证方式。真正新增的效力、运期或事件规则先准备具体来源与影响清单，再向用户确认启用；不得将学习资料整篇转成可用规则。真实案例仍按命主和答案隔离，结果与体验分别定义，不通过用户共鸣代替验证。

原v3修复的是裁决、个体体验和交付验收；本次独立批准的增补实际扩展了方法和动态事实，不自动补齐所有盘的净判断。试用分别记录条件方向、净方向、具体事件和是否回答主问题；没有方向的样例仍保留，不能以目录、代码或复审通过宣称现实预测能力。
