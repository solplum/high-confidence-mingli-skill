# 判势能力与依据缺口

这是v3的维护盘点，说明当前资料和自动模块的覆盖，不是永久禁判表。分析者先查实际适用资料与条件：能够人工裁决的内容按统一方法给结论；真正缺少的依据具体列出，不能只因自动面板未给吉凶就停止，也不能靠新增结论栏伪造能力。

| 层面 | 当前已提供 | 作进一步裁决仍须核查的内容 |
|------|------------|--------------------------|
| 八字本命事实 | 四柱、藏干、十神、冲合配对与齐字结构 | 事实存在不等于作用有效，需保持透藏、位置、时间与竞争关系 |
| 旺衰与喜忌 | ST01～05比较支持/反向路径，只在窄条件下给趋势 | 完整司令、相对作用、冲合对根和藏干的效力、特殊格与调候；不从生助直接判喜、从克泄直接判忌，现实偏好不替传统喜忌 |
| 格局与救应 | 月藏同干透出候选、官伤印/食杀印财方向、五合角色和用神语义 | 从候选到成格、救应是否有效及主次裁决的来源与条件；某路线无候选不等于全盘无格 |
| 八字时段 | 大运粗年龄表、年度字段、历法年月日与边界可核 | 对应时段如何与原局需求及有效关系相接、反向条件和作用主次；同柱、单个冲合或正印日不自行证明当日吉凶。精确交运与可支持的时间尺度分开核查 |
| 紫微本命 | 命财官迁有限星性主题、原始亮度、固定本命四化附着、空借/辅星/宫位结构、三个窄观察主题 | 完整组合、空宫借星效力、辅煞权重、多化修饰与其他领域规则；结构条件足够不代表每种现实结果都已有依据 |
| 紫微时段 | 大限位置/年龄与CLI现有年度固定四化表可重放 | 当期完整字段、所用动态规则和领域/时段适用性；本命、十年或年度资料不压缩为某天好运 |
| 七政 | 已选择版本的天文/传统口径、本命度主关系分类；明确选择时的乾元受限参照 | 当前无月限/小限应期，宿界及多项规则仍有限；算出某日天体位置不等于已有日级判势规则，不借别盘替代 |
| 性格与体感 | 用户有来源的自述/偏好及可撤回的性情假设，可解释适配、感受和成本 | 核对信息身份与相反实例；未知时条件分支，已知时采用对应分支。性格不能补造外部机会、流日效力或喜忌 |

这些缺口不要求每次分析全部补齐。按所问问题找决定性缺口：若只问工作方式，已有关系与合法现代综合可能足够；若问具体某日整体顺阻，需要真正支持这一时间层和评价对象的依据。不同领域的结论强度可以不同。

补库优先记录：要回答的问题、需要的规则/输入、已有来源覆盖、尚缺条件、反例和验证方式。真正新增的效力、运期或事件规则先准备具体来源与影响清单，再向用户确认启用；不得将学习资料整篇转成可用规则。真实案例仍按命主和答案隔离，结果与体验分别定义，不通过用户共鸣代替验证。

本轮v3修复的是裁决、个体体验和交付验收。现有目录来源数、记录数与原始引擎能力未因方法升级自动增长；不能宣称已补齐所有日级预测能力。
