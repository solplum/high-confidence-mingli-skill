# 已批准的有限模型判读方法 M0

用户于2026-11-10批准本方法及《穷通》子月辛金的窄用途增补。M0是作者的有限缺省模型与比较方法，服务于传统文化解释；不是古籍中的通用排序公式，也不证明现实预测有效。三盘仍各自遵守来源、事实、规则用途和时间合同。

## 何时使用

本题已有获准、完整且直接评价所问整体或领域的条件规则时，按下列步骤形成条件模型结果。来源只有生克定义、星性主题或节点配对时，先完成从关系到原问的比较；M0本身不提供这条连接。名人案例的后来成就也不能代替通用规则对本题的评价。

《穷通》子月辛金的整体／发展配置按 `bazi-qiong-xin-zi-v1` 的 QX01–03 及[模块说明](bazi-qiong-xin-zi.md)核查。实际读取所选分支、另一读法和共同反条件。丑月辛金用 [BZ-QXC01](../references/approved/bazi-qiong-xin-chou-v1.md) 核本命专业发展配置，寅月甲木用 [BZ-QJY01](../references/approved/bazi-qiong-jia-yin-v1.md) 核学习支持与可核验专业成果的配合。各卡分别核其出生节令、必要条件和许可层级。

## 形成结果的顺序

1. **固定问题和事实集合。** 写明评价对象、领域、目标、时间窗、场景及所用来源。分开本命必要条件与作者时间适配事实；所需事实缺失时保留缺口。
2. **核完整分支。** 必要条件逐项回指事实，分开已满足、不满足、未知。对已匹配结构，缺省作用只允许采用所选来源分支的正负评价；身强、壬多、成局、已解印、合化或规则另外要求的实质效力，各须自身依据。

   对已获准且用途适用的通用条件规则，若其明确由一组前提推出某项模型作用或评价，前提及反条已核后，该规则本身可以是该结论的依据，不另设未定义的二次效力认证。先分清该项在条目中是前提还是结论；未由本条推出的成格、身强等必要前提仍各须依据，不可由待求结论倒证，也不解除原条目的用途／效力限制或用个案替代通用规则。
3. **核反条，再裁决。** 先检查来源特指反条，以及其他适用依据是否否定本支必要条件。已成立阻断则受限或改判；决定性条件未知则分支化或未决。反向依据即使不是完整总体评语，只要能否定必要条件，也必须进入裁决。
4. **比较其余路径。** 已匹配且直接评价本题的具体规则，可优先于只有一般生克／配对、尚无适用依据证明否定效力的路径。后者记录实际节点、作用对象和未决风险，不能据此自动推翻完整模型，也不能认定零影响。有依据支持的负向作用才称代价。具体负评与泛泛正向的比较采用同一原则。
5. **同时交付方向和稳健性。** 给所选分支下的条件模型结果，说明异读、尚未裁决的作用及翻转后果。完整规则已有相对有利、受限等评价时，正文直接表达相应的条件方向，不能退成只列“支持信号”或主题而不回答所问问题；受限不升级为现实事件必败，正支退出也不自动判差。若未决路径实会阻断所需用途，原正评退出或改判；负评亦按同样标准修订。模型有方向而稳健性有限时，两项一同呈现。

完成标准：能从记录复核所选规则、必要事实、已查反条、剩余风险及它们怎样改变结果。只假设“一切破坏都不存在”，而无完整匹配规则和必要事实，不构成可用模型。未取得正支不自动等于负评；尚未检查也不能称方向稳定。

## 运期与整个区间

先冻结本命模型及适配判据，再按BJ06–08核实际大运、年、月、日及相关边界。对子月 QX01–03 分别记录本命源义和已批准的作者运期适配；来字不改出生月令、透藏与原始状态。原局丙藏而运年丙透时，只能在明确的动态适配集合里检查，不能改称源文本命条件已成立。丑月 BZ-QXC01 和寅月 BZ-QJY01 只提供本命背景，所问时段的方向须有另行适用的依据。

本期方向可综合上层背景与本期新增条件，不要求先为每个增量各贴一个吉凶标签。但须实际核来字、反向路径和整个所问区间；上层有利不能直接复写成今日／今月有利。增量净效力未决时保留未决，不能说它微弱、为零或已由风险主导。点查询只代表该点及已核稳定范围。

## 四层分别记录和复审

| 层次 | 本次要保留的内容 |
|------|------------------|
| 盘面事实 | 原始事实、场景和时间范围；本命与适配集合分别定位 |
| 条件模型结果 | 所选来源分支、必要条件与反条检查后的方向；传统源义与作者方法分别标明 |
| 稳健性 | 另一有依据的读法、未决作用风险、条件敏感性，以及何时退出或改判 |
| 现实效度 | 是否有预先确定且同对象的真实结果可比较；暂无真值则未知，模型／合成检查不计现实准确率 |

正文先给条件模型对原问的回答，同时说清实质异读和翻转条件。完整规则的发展评价可以支持相应模型方向；它不直接证明外部机会增加、录用、考试、收入、婚恋结果或健康事件。其他领域继续使用各自已获准规则和边界，紫微／七政不因本增补扩大范围。

若将模型用于生活方向的后续反馈，在反馈前固定可观察目标、区间、条件与判定方式。实际不符如实保留未命中；不能从不符结果反推不可观察的“根其实无效”等隐藏条件，使原判永远成立。确有独立新事实时保留原判、失败及修订理由。没有对应真值时不报准确率。

六模式分别验收：详批解释有源配置与领域，具体问题核所问目标，运势检查实际区间，共鸣分开条件与现实自述，知识说明交代版本和选读，收束保留原判与真实反馈。全部仍按[共享流程](../workflows/fortune-auditable-reading.md)单独复审，完整正文默认在当前对话交付。
