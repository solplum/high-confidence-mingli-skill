[原文件](https://upload.wikimedia.org/wikipedia/commons/4/4e/NCL-06601_%E4%B9%BE%E5%85%83%E7%A7%98%E6%97%A8.pdf)的 SHA256 为 `1fffb642558dc78810446822a182c8550d811ed337f4e5835168500cf0674aa5`。网页阅读器因11MB大小无法载入，直接下载同一个公开文件成功；没有绕过权限或403。扫描在研究临时目录，不入Git。可复核者应下载此文件先核hash，再按以下**PDF页序（从1起）**查看。不能把页序直接当古书叶码。

- 第17页右半：十二宫分度数相照；180、120、90、60度；立命与立度。左半为续文和十二宫名目。
- 第18页：十二宫解释续文及限年、出童限。本轮阅读但不启用年数与起限算法。
- 第19页左半：定命、行限。可清楚读到短语“定命專論宮”“行限專論度”。定命段紧接着提及果老论度不同；行限段分别以房、心、尾、箕等宿举例，反对宫度混论。
- 第20页：命主及经、络。提示同类宿关系并非两星实测角距离；本轮不自动展开全部经络规则。
- 第21页左半：填、冲、守；冲段用子午举例并明说“不必拘于”180度。右半贯、串不作新自动断语。
- 第22页右半：钓、拱；以卯与亥未、申与亥寅巳说明三方四正，亦说明不必拘于精确120/90度。左半夹的具体吉凶条件只读，不启用。
- 第23页：夹续文、拦截、天官等；冬生水孛与火罗的例子显示简单“混杂即坏”并不足够。本轮不实现它依赖的官魁、神煞和时令判断。

上述逐页核验是**一版局部影像核对**，不是全书逐字校勘、版本谱系证明或预测验证。图中眉批、残字和书页破损处未用来建立规则。没有把原库“讨为原刻字”等未经核验的注解升级为事实。

[卷四固定版本784372](https://zh.wikisource.org/w/index.php?oldid=784372&title=星學大成_(四庫全書本)/卷04)，[贡献历史](https://zh.wikisource.org/w/index.php?title=星學大成_(四庫全書本)/卷04&action=history)。页面归于万民英四库本，本文仅核其在线转录，未看此卷底本影像。

“星盘或问”区分地支五行与星盘宫所属；“看星节要八十一条”首条强调度主、宫主的不同职责。这是 QZT01 的文献背景与 QZT04 的异说线索，不把它当已校勘古文。日主折火、月主折水是本项目五行演算约定，不伪装成该问答逐字规定。已有宫主表继续有版本与语义限制。

## 五张可用学习卡

1. **QZT01 宫支与宫主。** 输入卯，分别显示地支木、宫主火、宫主五行火。说明为什么不能拿卯木代替宫主。反例传入伪造宫主字段不能悄悄覆盖。
2. **QZT02 庙乐术语冲突门。** 给“庙”并声明旧整理体系，返回暂不合并，而不是一个貌似精确的强弱分。本卡指出缺的并非计算能力，而是采用哪条定义及其可靠版本。未知体系同样不能判。
3. **QZT03 宫位关系与黄经差。** 合成子午两点相差175°时，支宫可属对照，而距180°仍差5°；分别输出。不会偷设5°容许度，不称两星已“相会”。二者均需调用者提供，不从一个反推另一个。
4. **QZT04 乾元定命宫主法。** 明确选择该语境和宫主基准后才演示五行关系。例如卯宫主火与金是“我克”；不是度主法的同名结果。只列关系，不命名恩仇，不判事件。
5. **QZT05 行限按宿主的演示。** 已给定心宿时，宿主是月，本项目折水；土相对于水为“克我”。没有真实起限、时间和限度算法，故仅是“假设行到此宿”的学习，不输出年龄和日期。

每卡有来源、定位、前提、反条件、白话说明和正反样例。允许条件推演，不允许把书中贵贱病寿婚财的古代断语落实为真实人的确定结论。绝对预测被排除，不等于内容只剩免责话语：本包具体回答参照对象怎么选、哪个关系能算、哪个概念不能互换。

## 证据链与测试边界

实际可复核链为：声明输入与语境 → 选择登记卡 → 核对必要字段 → 运行确定性关系比较 → 展示来源等级、前提和反条件。数据或选择不明则 withheld。所有通过的输出最多为条件性的传统结构演示，预测效度固定 unvalidated。

运行注册检查：

```sh
python3 scripts/qizheng_traditional_study.py validate
python3 -m unittest discover -s tests -p 'test_qizheng_traditional_study.py' -v
```

例如：

```sh
python3 scripts/qizheng_traditional_study.py evaluate --rule-id QZT04 --facts '{"context":"natal","reference_basis":"palace_lord","branch":"卯","other_element":"金"}' --format text
```

CLI的具体evaluate参数见 `--help`。合成例数据保存于登记卡，不能说是某人的实盘。调用者仍要负责所传事实真伪；注册hash只保证登记未意外变更，不验证古书或现实效果。

本包不向既有知识catalog自动注入个人reading规则，也不改变全局 `classical_quote` 禁止门。扫描短语只供本研究说明和定位，不授权模型将任意整章转成已核引文。
