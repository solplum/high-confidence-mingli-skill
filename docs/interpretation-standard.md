# 解释与判断方法 v3：明确裁决与个体体验

用户于2026-11-09批准v2的充分解释与现代转译，2026-11-10批准v3的全模式裁决与体感区分。本版保留v2的解释空间，增加从依据到评价、直接回答所问问题的完成要求。适用于三盘的个人分析、知识说明及收束；排盘、来源隔离、具体规则范围与许可仍遵循各自合同。

## 2026-11-10已批准的综合判读增补

在v3基础上按 [综合判读方法v1](conditional-judgment.md) 执行BJ01–BJ08人工比较，以及紫微独立动态事实与年/月主题、禄权条件解释。首选工作假说必须有本题适用的来源和主次依据，未检查的分支不算方向稳定；原ST/BZ-K状态与旧用途保持。BJ07流年、BJ08月日是作者受限时间外推，不能冒称已核原典日级算法。紫微日级效力、原文隔离和具体事件预测仍未启用。

## 解释要完成什么

按实际问题形成有实质内容的解读：本盘最值得关注什么、哪些关系相互支持或制约、整体可能呈现什么倾向、有什么优势与代价、何种条件会改变解释。依据支持条件判断时直接给出条件判断，再解释为什么。问题可用于核实假设，不要求把所有解读都改成提问。

核查后的正文须有本盘的具体含义和判断；程序清单、百科定义、通用建议和反复暂缓不能替代这项工作。某个环节存在缺口时，明确限制受影响的部分，充分解释其余有依据的内容。用户要求短答时可压缩呈现，研究要求不变。

## 先回答问题，再给建议

运势先回答在所问时间和领域内总体偏顺、平稳、偏阻还是有依据的分化；具体问题给适合与否、较推荐路径及关键前提；详批给主要优势、制约和适配方式；共鸣给匹配结论；知识问答给清楚定义、作用和适用利弊。具体模式决定需要什么结论，不强制所有模式都填吉凶标签。依据足够时直接给定性判断，不要求程序先产生分数，也不要求来源原样写出综合句。

主结论说清对谁、什么目标、哪个领域和时段，哪一方向较占优势、主要代价及何种变化会翻转判断。读完前两段应能找到对原问题的直接回答。行动建议接在判断和理由之后，不能用“建议认真准备”代替“这段是否有利”的答复。

## 外部形势、目标推进与个人体感

| 评价对象 | 需要回答与核对的内容 |
|----------|----------------------|
| 外部形势 | 对应时间层内的机会、支持、约束和变化。传统推断保留资料与条件身份，现实已知情况注明来源；不能从一个生、克、冲或化禄直接判好运坏运 |
| 目标推进 | 这些条件对当前目标的支持、阻力、可行路径和成本。不同目标可有不同适配判断，现实建议与传统判势分别说明依据 |
| 主观体感 | 命主可能感到轻松、费力、受支持或受约束；使用有来源的性格、偏好和现实背景，不把舒适等同成功或把压力等同失败 |

正文自然表达，不机械填满三栏。“推进有利、过程耗力”可以同时成立，但两项均须有依据；不能以“会让你成长”美化已识别的阻力。对某项行动的建议不是外部好运的证据；没有外部结果依据时，不用另外两项顶替。

先固定盘面和时段依据，再按所问目标作评价，加入性格、偏好与现实背景解释体验和应对成本。优先用已确认自述，其次用注明身份、可被反例撤回的性情假设。未知时给有意义的条件分支；已有确认信息时采用相应分支，不仍以“可能安心也可能受束缚”回避裁决。性格若影响实际行为和目标适配，要说明这条连接，不能仅换一个性格描述就改写外部机会。

例如，同一组已核的规则与复核要求，对偏好清晰标准者可能更安心，对重自主探索者可能更费力；体感差别不改变已核结构。个人喜欢学习不等于传统喜印，现实偏好不能补齐喜忌、制化效力或当期规则。不能先从盘面假设性格，再把同一假设当作独立证据支持运势；也不能等用户否定后才补性格理由让原判永远成立。

## 有相反依据时作比较与裁决

只比较同一时间、领域、目标和评价对象的支持与反向条件。说明为何取某一方向为主，哪些只是代价，哪些足以阻断或推翻结论。可人工比较与问题的关联、条件满足程度、资料对作用的支持和反向连接；不按条数、五行数、星数或盘数投票。整体判断交代如何从领域结论归纳，不默认事业比其他目标重要；目标优先级不明且各域方向不同时，明确分别判断。

有依据显示不同领域方向不同，才称“分化”；有依据说明平稳，才称“平稳”。关键作用未决或证据不能比较时，直接说“该项目前无法定性”，指出决定性缺口，不能把未知写成中性、平平或好坏相抵。其他可判断的部分继续给结论，不把局部未决扩大成全篇拒答。

## 四种内容各有身份

| 内容 | 依据与表达 |
|------|------------|
| 盘面事实 | 使用实际引擎字段、柱位、宫位与场景，透藏、实坐/借星、固定本命/动态标记分别保留 |
| 传统释义 | 回指可定位且用途适用的资料；项目整理、现代说明和古籍原文按真实身份引用 |
| 现代转译 | 作者为理解关系所用的当代语言、比喻或行为假设，说明从哪些事实和关系转来 |
| 综合推论 | 将多项关系联系后形成的条件判断，交代推论环节、相反路径、主要替代解释及范围 |

正文可自然连贯地写，一次说明哪些部分是作者解释，在证据记录中分别定位。每个现代词或每句综合不必预先登记成独立规则；实际借用的传统规则仍有资料依据。登记只含关系定义时，现代转译不改称“已核传统人事象义”。作者解释也不包装成古籍原句、测得人格或已发生事实。

## 现代转译与综合怎么展开

本次明确允许围绕实际官伤印财关系，采用“规则或要求、表达或改进、学习或依据支持、资源投入或成本”等现代议题，讨论支持与张力。这是解释方法中的作者转译示例，既不是把现代词加入古籍原文，也不是由某一十神自动测定人的行为。

具体展开时，先说明哪些实际位置、透藏、相反方向与其他关系让这个解释值得讨论，再给出条件式的整体含义、优势和代价。分析自身五合时可进一步讨论主体与相关要求的关系，说明该现代假设的推演距离，结合其他条件；一对配对不能独自确认责任内化、自我评价或关系结局。

允许“若这些关系在本问题中发挥作用，较值得关注……”“一种可能的倾向是……”。多项关系可以支持卡片没有原样写出的综合，但须解释它们如何共同支持结论，而非拼接关键词。相反路径有实质分歧时，充分解释两条路径以及何种条件使其中一条更适用；未裁决的作用效力保持未裁决，不把事实并存写成力量相等。

岗位、训练、资源、生活经历等更直接的现实解释应进入比较。用户自述可作为现实输入，注明来源；反馈不追记为排盘独立发现。现实反例可使假设不适用，不另造不可反驳理由保住解释。

## 自动面板与人工解释

自动模块未编码、未计算或未裁决某项，不等于已有资料与本版方法支持的人工解释一律禁止。先查状态原因，再决定能解释哪部分；保留自动输出原值，在人工解释记录中写出新增分析及依据。

两类缺口分别处理：

- **自动化范围有限**：可继续检索适用资料、比较实际关系，并按本版方法作条件解释。不能把未做过的研究标成已完成。
- **实质条件缺失或不满足**：未知时刻、星位不符、来源被隔离、关键规则/效力未获支持等，限制相关结论。现代转译不能将藏干变成透干、分宫变同宫、借星变实坐或流年四化变本命。

完整旺衰、调候、成格、喜忌、制化效力与具体事件判断仍须其自身资料和必要条件，不能由现代比喻补齐。本版不更换学派、计算口径或时间规则，不解除来源隔离、古籍逐字引用或特定模块用途限制，也不新增具体人生事件/应期预测规则。

## 记录、复审与对照

重要解释使用现有 ledger 能合法表达的 claim，或受限模块的独立人工解释记录。记录唯一ID、实际事实/场景/模块定位、资料依据、作者转译与综合过程的简洁摘要、判断范围、反向条件、替代解释及复审处理。无需复制整包输出，也不另造一套 JSON 协议。

`conditional_module_only` 的来源仍不转成通用 ledger rule；原始面板和人工解释共同保存。合法 ledger claim 的 statement/explanation 可包含明确的作者转译，但实际引用的 rule 仍引用真实来源，不为现代词虚构古文。机器校验与语义审核的实际通过、失败或未运行分别记录。

复审同时检查推演是否成立、解释是否充分、原问题是否已被回答：字段和条件有无错，资料与作者观点有无混淆，是否比较相反路径、语义跨度是否合理，以及是否过度收缩成清单、问题或全篇暂缓。主结论须能定位评价对象、目标与时间层、主次依据、个体体验的来源、代价和翻转条件；检查建议冒充运势、未知冒充中性、性格事后圆说。有事实链和合理范围的解释优先修订后保留；与盘面无联系、越过硬条件或伪称现实事实的部分应降级或撤回。只有语言充分或没有越界，仍不足以验收答非所问的报告。

跨盘对照回指不同体系已有的合法 claim 或人工解释记录ID/定位，保留同领域、同时间、场景及用途要求；现有七政受限面板的个人事件合参限制仍适用。对照是解释之间的比较，不产生独立验证、可靠度星级或预测准确率。

## 写法示意

以下是解释方法示意，实际使用必须重核本盘事实与完整条件，不是新增传统规则：

- **官伤印财**：实际有伤官制官、印制伤而财又制印时，可将其转译为要求、表达、学习支持与投入成本之间的张力。较有建设性的路径可能是让意见经过学习和依据整理后落实，代价可能是过度复核压住表达，或资源不足削弱支持。说明各方向的具体透藏位置，并保留哪条有效尚未裁决；不直接认定本人守规矩、叛逆或擅长管理。
- **自身五合**：月干戊与日干癸配对时，解释日干参与和“官被其他干合走”的角色差别。进一步讨论主体与要求的关系时标明现代假设，结合其他关系和现实情境；相邻仍不证明合绊或合化。
- **机梁命宫**：两星实际同坐命宫并满足登记条件时，可将情境调整与协调照应展开为一种可能的协作倾向，解释帮助与过度介入的两面。职责和训练是竞争解释，不愿介入的反例可以撤回该假设；实为借星或分宫时不采用实坐联合主题。

判势依据不足时，先明确原问题中哪项尚不能回答，再交付其他有依据的结论和具体缺口；不能把行动建议标作已经完成整体运势判断。维护者补库时参考 [判势能力与依据缺口](judgment-capabilities.md)，该盘点不是永久禁判表，合法资料与实际条件足够时应继续人工研究并裁决。真正新增的规则、资料解禁或计算变化仍先列具体范围请用户确认。

历史运行报告保留当时标准版本；本版实施后另存新解释与复审，不倒改旧记录或把旧试测称作新标准准确率验证。反馈记录分别保留原判断、实际结果、主观体验和修订理由；推进结果与感受可以一项相符、一项不符，不能事后合为“都算准”。
