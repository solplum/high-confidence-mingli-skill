# 实际引擎到证据记录的工程演示

这些输入是虚构的，不来自用户、好友或个案。这里没有“预测命中”数据。

## 复现

在仓库根目录执行：

```
(cd scripts/pai_pan_ziwei && npm ci)
python3 examples/engine-reading/generate.py
python3 scripts/validate_claim_ledger.py examples/engine-reading/ledger.json --root examples/engine-reading
```

脚本用实际三个引擎生成 6 个候选快照，不使用 stub。`commands.json` 保存每个命令；各快照保存输入、实际钟面、UTC 瞬间、源文件 SHA-256、紫微锁文件 SHA-256、实际目标年及警告。Python 日期类型转成 ISO 字符串，其余计算结构保留。本例显式使用 `--analysis-year 2026` 同时固定八字年度字段和紫微目标年；模拟运行年 2026/2027 的回归验证完整 JSON 一致。默认不传时保留旧行为；旧 `--age-year` 仍只控制紫微，不能用于全局跨年复现。源代码或依赖版本变化仍会改变快照摘要。

- `report.md`：七节非术语正文，有限解释与拒绝过推断。
- `ledger.json`：3 条有真实字段和本仓资料支持的有限判断、1 条“信息不足”合参。
- `boundary-results.md`：实际候选的差异。
- `*-source.md`：引用资料的逐字副本；来源及许可继承 `references/README.md` 与仓库 LICENSE，不冒称核对过原刊本。
- `validation.json`：此次结构校验结果。

## 已覆盖

五月午时基线；22:59 / 23:01 换日边界；同一民用瞬间的太阳钟面分支；同一引擎求得的立春前后两分钟。断言实际字段变化、七政对钟面切换的不变性，及 JSON 字段/逐字引文/场景链可校验。人工审阅把夏季总则降为待评估候选、区分空宫借星与实有星、因缺失身主而保留七政判断。这比占位 validator fixture 多验证了排盘、证据保存、解释限制与正文之间的通路。
